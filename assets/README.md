# 演示素材

演示录音在 `runtime/speech-test`，由 Windows Huihui 合成公开的测试句子生成，没有采集用户麦克风；转写文字是本地 whisper.cpp 实际输出，包含 tiny 模型的识别误差。

应用界面中的 SVG 图标由项目内 `src/icons.rs` 定义。设计目录的概念图是之前对话生成的界面参考，不作为运行时背景使用。
