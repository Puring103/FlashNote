# 当前需求与设计规则

## 视觉

风格：现代索引纸笺。纸面 `#F6F3EB`，文字 `#262D2B`，主要操作 `#234C50`，分隔线 `#CAC7BD`。分组辅助色为赭橙、灰橄榄、灰紫与中性灰。窗口标题栏同步使用暖白纸面。

保留小圆角和细边框；索引签贴在卡片上缘。不得加入玻璃、强渐变、卷角、厚重阴影或鲜艳 AI 标志。图标采用同一套细线 SVG，避免复选框等控件被系统渲染为彩色 Emoji。

## 窗口

中心窗口：顶部品牌、分组、搜索、新建、设置和回收站，主体为等宽不等高信息流。无固定左侧栏、无常驻详情栏、无“独立打开”文案。点击便签打开独立窗口。

小便签包含可选标题及混合正文，支持切换分组、手动置顶和返回中心。窗口可同时打开多个。

默认组永久保留，新建和未经整理内容进入该组。分组颜色作用于索引签和顶部线条，正文保持纸面色。

## 内容与语法

正文以结构化 Block 存储。文本块使用 Markdown，图片、音频、附件使用独立块。不是“一张便签只能选择一种素材”。Markdown 是快捷输入与文本格式，不承担音频状态和附件元数据的存储。

正文在同一区域原位编辑，输入 Markdown 时直接排版。加粗、斜体、待办和列表直接作用于光标或选区。

## 音频

音频条：左侧播放/停止，中间为真实波形和时长，右侧为展开箭头。收起时箭头朝右，展开时朝下。两个按钮分别点击，点击箭头不播放。

转写后的文字直接显示在同一张音频卡片内部。没有“展开文字”“已自动整理”“保留原意”等常驻文案。处理中只显示低强调的短状态，不显示伪造的百分比。原始录音保留，自动处理只做轻度文字整理，不自动生成摘要。

“想到什么，就先说下来”等句子属于示例内容，不是系统 UI，不应固定写在空便签或录音组件里。

## 内容省略

设计目标：预览高度约 360px；略微超出并可在 420px 内完成时尽量显示完整；明显超过时省略末尾。优先在段落/内容块边界截断，不切开音频控制条。便签展开与内部音频文本展开独立。

## 动效

窗口入场、分组切换与音频文字展开使用轻量动效。焦点和输入响应无需等待动画结束。
