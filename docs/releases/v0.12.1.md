# 闪记 0.12.1

- Windows 改为单文件安装程序。下载 `FlashNote-0.12.1-windows-x64-setup.exe` 后直接运行，可覆盖升级原安装目录中的闪记。安装和卸载都会保留本地便签。安装程序尚未签名，Windows 可能显示系统提示。
- Windows 和 Linux 发布包附带项目及随包组件的许可证。Android 继续提供签名 APK。
- 从 0.12.0 之前的版本升级自建同步时，请先备份，再升级同步服务和所有客户端。已经运行 0.12.0 同步服务的用户可以直接升级客户端。
