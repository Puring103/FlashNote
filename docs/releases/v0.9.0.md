## 闪记 FlashNote 0.9.0

- Windows 安装包包含闪记桌面端、`flashnote` 命令行和本地语音转写组件。
- Linux 提供 x86_64 压缩包，包含桌面端和 CLI，使用系统会话密钥环。构建基于 Ubuntu 24.04。
- Android 提供签名 APK，同时支持 ARM64 和 x86_64，可侧载安装。
- CLI 支持按标题、正文或录音转写搜索，批量读取和导出便签，新增、编辑和追加正文，管理分组和写入附件。
- 下载后可用 `SHA256SUMS.txt` 校验文件。

Android 的正式签名与调试版签名不同。若设备已经安装旧的调试版，先完成同步或另行备份，再从调试版迁移到正式版。卸载会删除设备上的本地资料。
