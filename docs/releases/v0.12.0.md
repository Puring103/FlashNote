# 闪记 0.12.0

- 客户端与同步服务器的单附件上限统一为 128 MiB。
- 普通文件和音频在加密上传前尝试无损压缩，其他设备下载后还原原文件。
- 100 MiB 以内的图片直接同步。更大的静态图片只在至少节省 20% 空间时采用压缩副本，导入设备保留原图。
- 自建同步用户请先备份，再将同步服务和所有客户端一并升级到 0.12.0。新版客户端需要服务端的同步检查接口，旧客户端无法读取新版压缩附件。已有附件可继续读取。
