# 新功能实现与交互约定

本文保留该日期的记录。当前设计与最近一次复核见[核心架构与同步设计](核心架构与同步设计.md)和[2026-11-25 审查](架构审查-2026-11-25.md)。

本说明覆盖 2026-11-16 确认的新功能。概念图只用于设置布局参考，卡片继续沿用现有原位编辑器、字体、分组下拉和不等高信息流。

## 设置

点击中心设置按钮，在同一窗口中切换为完整设置页面，顶部提供返回便签和窗口控制。侧栏分为常规、账号与同步、数据管理、分组管理、关于与更新。托盘入口打开同样的完整页面，默认尺寸为 1100×800；不再使用原来的 530px 小设置窗口。

- 常规：开机启动、减少动态效果、两个全局快捷键、语音模型与自动转写。
- 账号与同步：账号登录/退出、账号管理、同步状态、当前会话最后成功时间、待同步变更数量、空间用量和重试。
- 数据管理：ZIP 导入导出、空间统计、历史保留、回收站。
- 分组管理：名称与样式、顺序、迁移后删除；默认分组不可重命名或删除。
- 关于与更新：版本、发布页面、程序目录、退出。发布页面需要相应仓库访问权限。

## 便签与多选

卡片右键提供打开便签、多选、导出、移入回收站。删除了卡片上的悬停删除按钮，以及时间区域的双击打开行为。单张移动分组继续使用左上角下拉，右键不重复提供入口。

右键“多选”会选中当前卡片。多选期间，点击卡片任意位置切换选择；正文、待办框、音频和分组控件不会执行原操作。卡片显示细墨绿选中边框及线条勾选图标，不改变卡片内容样式或高度。

底部工具栏提供全选、移动分组、导出、移入回收站和完成。Ctrl+A 选中当前筛选下的全部结果，Shift+点击按创建时间列表顺序连续选择，Esc 退出。切换分组或搜索条件会清空选择。右键未选卡片会将其加入当前选择。

移动和删除在单个 SQLite 事务内完成。成功后退出多选，可以撤销最近一次批量操作；如果便签之后发生编辑或同步，撤销会拒绝覆盖更新后的内容。回收站多选提供恢复、导出和永久删除。

## ZIP 格式与导入

ZIP 包含 `manifest.json` 与 `assets/<uuid>`。清单保存便签结构、分组、时间和附件引用。不包含机器密钥、账号令牌、设置或历史修订，不需要口令。

导出在后台完成，先生成同目录临时文件，完成后替换目标。单张与多选导出从右键或底部进入；数据管理导出全部便签，可包含回收站。

导入先在后台读取校验，然后显示便签、分组、附件和重复项数量。默认按便签 ID 跳过重复项；选择保留副本时生成新 ID，重新映射附件，已有内容不被覆盖。新分组与便签在一个事务内提交，失败时撤销数据库写入并清理本次新附件。

校验压缩包版本、重复路径、越界路径、符号链接、对象 ID、分组关联、附件完整性及解压大小。当前上限：20,001 个文件、16 MB 清单、512 MB 解压总量。历史上限之外的大型迁移需后续流式导入支持；导入最终写入阶段仍在应用线程执行。

## 历史、回收站与空间

默认保留全部历史，可选择 30、90、365 天；点击清理时执行保留策略，不在后台自动删除。当前版本、同步基线和未确认上传的修订不会删除。附件只有在当前便签、保留历史、同步基线均无引用时才清理。

永久删除只针对回收站，执行前确认数量。删除本机正文及历史，同时保留不含正文的删除标记供离线设备同步。同步基线或其他设备仍保留的附件不会被强制清除；不承诺立即擦除服务器全部历史密文。设置页最多列出前 100 条回收站记录，全部内容可在中心回收站查看。

## 安装与更新

`scripts/package.ps1` 构建并打包程序、安装脚本和可选语音运行时；输出位于 `runtime/packages/`。包中的“安装或更新.cmd”安装至当前用户 `Programs/Suojian`，添加开始菜单快捷方式。再次运行会更新程序并保留独立的 AppData 数据。安装器不会强制关闭程序，更新前应从设置退出。

目前提供手动更新包与发布页面入口；没有自动下载替换流程和代码签名证书。

## 验证

- Rust 全工作区单元与集成测试：97 项通过，1 项需要线上测试账号的测试跳过。包括 ZIP 往返/重复项、损坏包、路径越界、失败回滚、批量事务、永久删除标记、分组迁移及两设备同步。
- Python 同步与账号服务测试：26 项通过。
- 使用独立 `runtime/feature-ui-test` 数据库进行真实 Windows 界面验收，不操作正式便签。
- 实机已确认设置占满窗口、侧栏切换、右键菜单、多选点击待办/音频不执行内容操作。全选快捷键的焦点问题已修正并编译；用户按 Esc 停止电脑操作，修正后的 Ctrl+A / Esc 尚未完成实机复验。
- 安装脚本在独立 `runtime/install-validation` 目录执行成功，安装后的主程序 SHA-256 与安装包一致；测试未修改开机启动或开始菜单。
- `cargo fmt --all --check`、`git diff --check` 通过。

仍需在大数据量、不同 DPI/显示器和真实安装环境下进一步验收。线上账号集成测试需要明确测试账号，因此默认跳过。
