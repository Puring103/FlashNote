## 直接开始

在项目目录双击 **打开同步测试-A.cmd**。切换到 B 前，先从索笺设置中选择“退出索笺”，再双击 **打开同步测试-B.cmd**。关闭窗口会驻留，不能代替退出。

分类较多，顶部分类栏可以横向滚动；在分类栏上用 Shift + 滚轮，或触控板横向滑动。搜索作用于当前分类，跨分类查找时先选择“全部”。

| 入口 | 作用 |
|---|---|
| 打开同步测试-A.cmd | 启动本机同步服务，打开 A 的演示库 |
| 打开同步测试-B.cmd | 启动本机同步服务，打开 B 的演示库 |
| 暂停测试同步.cmd | 停止本项目的测试服务，保留本地编辑能力 |
| 暂停图片测试源.cmd | 停止 47832 端口的图片源，便于测试下载失败及重启恢复 |
| 离线打开测试-B.cmd | 打开 B，不自动恢复服务 |
| 同步测试库.cmd | GUI 退出后，恢复服务、汇合 A/B 并验证一致性 |
| 补充测试案例.cmd | GUI 退出后，只补缺失案例；已有编辑和回收状态保留 |

补充案例前自动复制两份完整数据到 `runtime/sync-local/demo/before-cases/<时间戳-随机ID>/`。v3 目录备份中的正文和原始附件为明文，密钥包装与配置仍加密并依赖当前 Windows 账户。应用导出的口令保护便携备份仍整体保护内容。不要把目录覆盖回运行中的数据。

## 推荐的人工检查

1. 打开 A，逐个切换分类，选择一张短便签修改，勾选一个清单。退出重开后确认保存。
2. 搜索 `CASE-I`，观察宽图、长图。图片分类 I01/I02、混合素材、回收站 R03 复用同一张钢笔照片。
3. 搜索 `CASE-A`，播放音频并展开转写。A01 文本是演示转写；A03 失败状态人为设置，音频有效。真实转写需要本机 whisper 配置。
4. 打开文件分类，检查文件名和卡片。F04 解密后的内容为零字节；F05 为 1 MiB 的测试数据文件。
5. 切到回收站，恢复 R01 或 R03；恢复 R03 后确认图片仍可预览。也可把 R02 删除后再恢复。
6. 设置中查看“已同步”和云端容量。退出 A，打开 B，检查这些变化。

应用没有“永久删除回收站”入口。移入回收站不释放附件空间；撤销所需素材、其他便签复用素材也继续占空间。空间按密文实际字节计算，包含封装开销，因此不等于所有原文件大小直接相加。

## 亲手测试离线合并

两台演示设备轮流打开。使用 **暂停测试同步** 停止本机服务即可模拟离线，不必断开电脑网络。

1. 联网打开 A，新建一张便签，写三段：`第一段`、`中间锚点`、`最后一段`。等设置显示“已同步”，退出 A。
2. 打开 B，确认这张共同起点已经出现，退出 B。没有共同基线时，两张新建便签会按不同 ID 分别保留。
3. 打开 A，双击 **暂停测试同步.cmd**。修改第一段，等待自动保存，从设置退出。服务离线时同步失败提示是预期表现。
4. 双击 **离线打开测试-B.cmd**，修改最后一段，等待保存并退出。这个入口不会重启服务。
5. 双击 **同步测试库.cmd**。脚本启动服务并执行多轮同步，核对 A/B 对象、加密附件及空间账本。
6. 打开 A 或 B，两处修改应同时存在。若把第 3、4 步改为修改同一段，应保留两份内容，其中一张标记“离线冲突副本”。

还可分别测试：A 删除 / B 修改；A 移动分类 / B 修改正文；A/B 各新建一张含附件的便签。完整自动化测试另覆盖断线重试、确认丢失、事务回滚、认证失败和配额。

## 已生成的同步结果

- C01：第一段来自 A，最后一段来自 B，自动合并为一张。
- C02：电脑“周六整理照片”和手机“周日整理照片”分别保留，手机内容带冲突副本标记。
- C03：原便签在回收站，手机离线补充的内容保留为正常可见的冲突副本。
- C04：A 把便签移动到工作分类，B 修改正文，两项结果同时保留。
- N01 / N02：分别在 A/B 离线新增，最终两份库都存在。
- C05：真实冲突后选择保留本地，原便签为 B 的内容，副本在回收站。
- C06：真实冲突后选择保留云端，原便签为 A 的内容，副本在回收站。
- C07：真实冲突后两份都保留，副本已经标为已处理，不再弹窗。

新图片案例的来源只在本机 `127.0.0.1:47832`，测试入口自动启动，不依赖公网。I05 经重定向后成功下载，I06 故意返回 404，I07 提供可复制的网页 `http://127.0.0.1:47832/page`。暂停图片源后，向便签粘贴 I07 的 Markdown 图片示例，退出重开仍应有待下载占位；从正常测试入口重开恢复图片源后，最多 30 秒或点击“重试下载”即可完成。已经下载的图片不再依赖图片源。

聚焦打开冲突便签，或点击副本上的“离线冲突 · 点击比较”，可以比较正文、修改时间与素材数量，选择保留本地、云端或两份。选择后切换设备，应该看到相同结果且不再次提示该冲突。素材原件在便签中查看；对话框不做图片或音频差异预览。

这些结果通过真实 HTTP 服务和客户端合并路径生成。重复补充不会重放冲突，也不会覆盖你对案例的修改。中途停止后重新运行会保留已存在的便签；若某个场景未完整生成，用新的便签按上述步骤重测即可。

图片当前使用固定高度、裁切填充的缩略图，尚无点击放大的查看器。宽图和长图案例用于观察裁切与窄窗口效果；便签中提到的“放大”可作为后续体验需求，不属于当前已实现功能。

云端仅保留最新快照和删除状态；H01 的三版旧历史仅在 A 本机，不会同步成 B 的历史。

## 数据与核对

- A：`runtime/sync-local/demo/device-a`
- B：`runtime/sync-local/demo/device-b`
- 服务器：`runtime/sync-local/server/sync.sqlite3`
- 案例生成报告：`runtime/sync-local/demo/cases-report.json`

工具要求显式的数据目录。退出 GUI 后可以只检查、不写入业务数据：

```powershell
$env:SUOJIAN_DATA_DIR = Join-Path $PWD 'runtime\sync-local\demo'
.\索笺同步工具.exe verify-demo
```

检查包括：A/B 所有便签和分类逐对象相等；本地原始附件字节一致；图片可解码、WAV 可解析；云端对象数、附件密文缓存大小和空间账本一致。报告描述的是生成时刻，后续编辑请重新运行验证。
