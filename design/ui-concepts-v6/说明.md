# V6 窗口概念图

使用内置 imagegen 生成，依据当前 GPUI 矩形窗口、暖白底色、墨绿主色、顶部分类、信息流和单栏编辑器制作。图片不是运行截图。

[Windows 窗口概念图](02-windows-corrected.png)

生成规范：普通 Windows 矩形窗口；#F7F3EA 背景、#262723 文字、#245356 主色；细边框、统一线性图标。展示主窗口、正文编辑、新建分组与设置。录音播放左侧，展开箭头右侧；新建分组有六色选择。无预览/编辑切换。

修正提示：删除主窗口导航下的标题、记录数和排序文案及其空白；卡片上移直接跟随导航。Markdown 示例以标题字体、真实圆点列表等渲染结果显示，不能出现 # / ## 原始标记。展开的录音箭头朝下。其余维持既有配色与窗口结构。
